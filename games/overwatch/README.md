# Overwatch PS4

Plugin binaries live under sprx/<version>/<hash>/. version.json is the current download pointer, created only after verified staging.

Editable resources live under downloads/<category>/; downloads/catalog.json lists downloadable items. Categories are reserved for future support; an empty list offers no downloads. PC packs are not PS4-compatible by default. Never place account.json, passwords, device IDs or private configs here.
